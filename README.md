# 🛒 Retail Store SQL Analysis

## 📌 Overview

This project analyzes a retail store database using SQL to explore customers, products, orders, order items, payments, and product reviews. The project covers SQL concepts ranging from basic data retrieval and filtering to aggregations, multi-table joins, subqueries, and set operations.

## 📂 Repository Files

* `retail_store_analysis.sql` — SQL queries covering all levels of the analysis.
* `retail_store_query_results.pdf` — Project questions and executed query results.
* `README.md` — Project overview, techniques, insights, and recommendations.

## 🛠️ Key Techniques

* Database querying and data retrieval
* Filtering with `WHERE`, `IN`, `BETWEEN`, `LIKE`, and `IS NULL`
* Sorting with `ORDER BY`
* Column aliases and calculated fields
* String and date functions
* Aggregate functions including `COUNT`, `SUM`, and `AVG`
* Grouping with `GROUP BY`
* `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`
* Subqueries using `IN`, `NOT IN`, `AVG`, and `MAX`
* Set operations using `UNION`

## 🔍 Key Insights

* Customer ordering activity was analyzed to identify customers who placed orders and those who did not.
* Product pricing and category-level product information were analyzed.
* Total orders, total revenue, average order value, and active customers were calculated.
* Sales volume and average product price were analyzed by category.
* Order activity was examined by date and payment method.
* Products that were sold and products that were never ordered were identified.
* Highest-value orders were identified for individual customers.
* Customer activity across orders and product reviews was analyzed.

## 💡 Recommendations

* Monitor products that have never been ordered to support inventory and product decisions.
* Analyze customer ordering patterns to identify opportunities for targeted marketing.
* Use category-level sales and pricing analysis to support product and inventory planning.
* Monitor payment-method usage to understand customer payment preferences.
* Track high-value customer orders to identify opportunities for customer retention and engagement.
